# Rust Perú Website 🦀

Sitio web oficial de la comunidad **Rust Perú**.

## Objetivo

Este repositorio contiene el código fuente del sitio web de la comunidad Rust Perú, donde se publica información sobre la comunidad, eventos, recursos y enlaces de interés para desarrolladores de Rust en Perú.

## 📁 Estructura del proyecto

```text
rust-peru/
├── index.html          # Página principal
├── background.avif     # Imagen de fondo
├── rust-peru.png       # Logo de Rust Perú
├── rust.png            # Logo de Rust
├── Dockerfile          # Configuración de Docker
├── docker-compose.yml  # Orquestación de contenedores
├── nginx.conf          # Configuración de Nginx
├── LICENSE-MIT
├── LICENSE-APACHE
└── README.md
```

## Desarrollo local

Si tienes Docker instalado:

```bash
docker compose up --build
```

Luego abre tu navegador en:

```
http://localhost
```
